# ZestBasket brand assets

The original brand icon is copied without modification from the adjacent customer project `hackaton/packages/design-tokens/assets/zest-icon.png` to `public/zestbasket-icon.png`. The existing shopkeeper vector mark is retained as `public/zestbasket-mark.svg`.

The admin mascot is generated with the built-in ImageGen tool, using the existing shopkeeper mascot, rider character artwork and original ZestBasket icon as references. It is saved as `public/zestbasket-admin-mascot.png` with transparency.

The original icon appears in the shared Logo component (login, sidebar and loading state) and browser favicon. The matching admin mascot appears on login, dashboard banner, sidebar support, sidebar profile, header profile and account page. Old custom basket/shield art is no longer referenced by the UI. Mobile artwork positioning is adjusted separately from desktop.

## Final generation prompt

Create ONE premium 3D cartoon ZestBasket ADMIN mascot matching the exact friendly male character design, face, swept dark hair, neatly trimmed beard, warm brown eyes, realistic soft 3D animation rendering of the shopkeeper and rider references. This is the administration member of that SAME brand family. He wears a smart rich purple blazer over an orange polo, with the ORIGINAL ZestBasket white basket-and-two-leaves logo from reference 3 as a small clean embroidered chest emblem. No shield, no new basket symbol. He holds a slim dark tablet with a subtle operations dashboard in one hand and makes a welcoming confident thumbs up with the other. Single person only, no other characters. Waist-up portrait, full head and hair and both hands entirely inside canvas, ample transparent margin, polished studio light and friendly professional expression. Genuine transparent background with no backdrop, floor, glow cloud, text or watermark. The reusable mascot will sit on login hero banners and profile cards in an admin web portal. Keep the purple and orange brand palette from the references. Output a clean square 1024x1024 PNG cutout.
